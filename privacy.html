適用範圍

本政策說明 Hana Personal Memory 私人本機助理設定如何處理資料。此設定只供擁有者本人及本人控制的 Google 帳號使用，不提供公開使用者服務。本網站僅為說明頁。

存取的資料

經擁有者以 Google OAuth 授權後，應用程式可讀取 Gmail 郵件內容、中繼資料和相關設定；Google 日曆清單與事件；Google Drive 檔案中繼資料與可讀取的文件內容；以及用來辨識帳號的名稱、電子郵件地址與基本個人資料。權限為唯讀。畫面情境資料由本機 Screenpipe 記錄，本設定停用音訊、鍵盤與剪貼簿原文記錄。

使用目的

資料用於回答擁有者的問題、回顧先前活動、整理相關資訊、辨識日程或期限，以及提供經允許的提醒與建議。應用程式不將這些資料出售、用於廣告投放，或自行建立用來訓練通用模型的資料集。

儲存與安全

OAuth 憑證、畫面歷史與本機助理記憶保存在擁有者電腦，不會上傳到本說明網站或 GitHub 原始碼儲存庫。OAuth 憑證所在資料夾限制目前 Windows 使用者與 SYSTEM 存取。這不表示所有畫面歷史均經過加密；擁有者應使用適當的電腦帳號、磁碟與備份保護措施。

雲端 AI 處理與其他分享

助理執行擁有者要求或允許的工作時，會將檢索出的相關資料片段交給擁有者設定的雲端 AI 服務處理。所選服務會依其適用條款、資料使用與保留設定處理這些片段；這些服務的設定不由本說明網站控制。擁有者應選用符合預期隱私要求與 Google 資料使用規範的服務設定。

除擁有者明確授權的處理、必要的安全處理或適用法律要求外，不另行對外分享資料。這個 Google 連接不提供寄信、修改日曆、上傳或刪除檔案的工具。

保留、刪除與撤回權限

本機歷史與記憶保留至擁有者決定刪除；目前沒有固定的自動刪除期限。擁有者可暫停 Screenpipe、停止助理、刪除本機資料，或到 Google 帳戶的第三方連線設定撤回授權。撤回權限不會自動刪除已保存在本機或先前已交給雲端服務處理的內容，後者依相應服務的資料設定處理。

Google API 資料規範

Hana Personal Memory 對透過 Google API 取得之資訊的使用與轉移，須遵守 Google API Services User Data Policy，包括 Limited Use 要求。擁有者應維持實際用途、雲端服務選擇與本政策所述用途一致。

說明網站的託管

本說明網站不設登入、表單、廣告或應用程式分析追蹤。若以 GitHub Pages 公開託管，GitHub 會為安全目的記錄訪客 IP 位址；詳見 GitHub 隱私聲明。
